## 1. Purpose

This log records every change made to any document in the CMP documentation
repository: creation, revision, review, approval, supersession, and deprecation. It is
the audit trail for the documentation programme.

## 2. Recording Rules

1. Every document creation or revision produces exactly one entry.
2. Entries are append-only. Existing entries are never edited or deleted.
3. Entries are recorded newest-last (chronological order).
4. An approved version is never silently overwritten; a new version and a new entry are
   created instead.
5. Where a change resolves a conflict with an approved document, the entry must
   reference the conflict and the Project Owner decision that authorized it.
